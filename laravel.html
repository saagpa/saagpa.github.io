Arsitektur MVC di Laravel

Laravel menggunakan pola MVC (Model-View-Controller) untuk memisahkan logika aplikasi menjadi 3 bagian yang berbeda.

KomponenFungsiLokasi
ModelMengelola data dan logika bisnis, berinteraksi dengan databaseapp/Models/
ViewMenampilkan data ke pengguna (tampilan/UI)resources/views/
ControllerMenerima request, memanggil Model, mengirim data ke Viewapp/Http/Controllers/

Alur Request MVC

Ketika pengguna mengakses URL, Laravel memproses request secara berurutan:

Pengguna → Router → Controller → Model (ambil data) → Controller → View → Pengguna

Contoh Sederhana

// routes/web.php
Route::get('/produk', [ProdukController::class, 'index']);

// app/Http/Controllers/ProdukController.php
public function index() {
    $produk = Produk::all();         // Model → ambil data
    return view('produk.index', [   // kirim ke View
        'produk' => $produk
    ]);
}
Tips: Pisahkan tanggung jawab — jangan tulis logika database langsung di View atau Route. Selalu lewat Controller → Model.
2

Routing di Laravel

Route adalah pemetaan URL ke logika aplikasi. Semua route didefinisikan di folder routes/.

FileKegunaan
routes/web.phpRoute untuk halaman web (dengan session, CSRF)
routes/api.phpRoute untuk API (stateless, prefix /api)

HTTP Method dan Route

// Basic routes
Route::get('/halaman', callback);       // Ambil data
Route::post('/simpan', callback);      // Kirim data
Route::put('/update/{id}', callback); // Update seluruh data
Route::patch('/ubah/{id}', callback); // Update sebagian
Route::delete('/hapus/{id}', callback);// Hapus data

Route dengan Parameter

// Parameter wajib
Route::get('/user/{id}', function($id) {
    return 'User: ' . $id;
});

// Parameter opsional
Route::get('/user/{name?}', function($name = 'Tamu') {
    return $name;
});

Named Route

Route::get('/dashboard', [DashboardController::class, 'index'])
    ->name('dashboard');

// Gunakan di Blade
{{ route('dashboard') }}  // → /dashboard

Route Group

Route::prefix('admin')->group(function() {
    Route::get('/users', callback);    // → /admin/users
    Route::get('/settings', callback); // → /admin/settings
});
Ingat: Route diproses dari atas ke bawah. Route yang lebih spesifik harus didefinisikan sebelum yang lebih umum.

Controller di Laravel

Controller adalah jembatan antara Route dan Model. Dibuat menggunakan perintah Artisan:

php artisan make:controller NamaController
php artisan make:controller NamaController --resource  // CRUD lengkap

Struktur Controller Dasar

namespace App\Http\Controllers;

class UserController extends Controller
{
    public function index()
    {
        $users = User::all();
        return view('users.index', compact('users'));
    }

    public function store(Request $request)
    {
        $data = $request->validate([
            'name'  => 'required|string|max:255',
            'email' => 'required|email|unique:users',
        ]);
        User::create($data);
        return redirect('/users');
    }
}

Resource Controller — 7 Method CRUD

MethodURLFungsi
index()GET /usersTampilkan semua data
create()GET /users/createTampilkan form tambah
store()POST /usersSimpan data baru
show($id)GET /users/{id}Tampilkan 1 data
edit($id)GET /users/{id}/editTampilkan form edit
update($id)PUT /users/{id}Update data
destroy($id)DELETE /users/{id}Hapus data

Validasi Request

// Cara yang benar — Laravel built-in validation
$request->validate([
    'name'  => 'required',
    'email' => 'required|email',
    'age'   => 'integer|min:0|max:120',
]);
// Jika gagal → otomatis redirect balik dengan error
Perhatian: Daftarkan controller di route dengan syntax [NamaController::class, 'method'], bukan string lama 'NamaController@method'.

Blade Template Engine

Blade adalah template engine bawaan Laravel. File Blade berekstensi .blade.php dan disimpan di resources/views/.

Keunggulan Blade: Syntax lebih bersih dari PHP biasa, mendukung template inheritance, otomatis di-cache untuk performa optimal.

Directive Utama Blade

{{-- Komentar Blade (tidak muncul di HTML) --}}

{{-- Cetak variabel (aman dari XSS) --}}
{{ $nama }}

{{-- Cetak tanpa escape (hati-hati XSS!) --}}
{!! $html !!}

{{-- Kondisional --}}
@if ($nilai >= 80)
    Lulus
@elseif ($nilai >= 60)
    Cukup
@else
    Tidak Lulus
@endif

{{-- Loop --}}
@foreach ($produk as $item)
    <p>{{ $item->nama }}</p>
@endforeach

Template Inheritance

{{-- resources/views/layouts/app.blade.php (layout utama) --}}
<html>
  <body>
    @yield('content')    {{-- slot untuk konten halaman --}}
    @yield('scripts')    {{-- slot untuk script --}}
  </body>
</html>

{{-- resources/views/dashboard.blade.php (halaman anak) --}}
@extends('layouts.app')

@section('content')
    <h1>Dashboard</h1>
@endsection

Mengirim Data dari Controller ke View

// Di Controller — 3 cara yang setara:
return view('users.index', ['users' => $users]);
return view('users.index')->with('users', $users);
return view('users.index', compact('users'));

Eloquent ORM

Eloquent adalah ORM (Object-Relational Mapper) bawaan Laravel. Setiap tabel database direpresentasikan sebagai sebuah Model class.

Membuat Model

php artisan make:model Produk           // Model saja
php artisan make:model Produk -m         // + Migration
php artisan make:model Produk -mrc       // + Migration + Resource Controller

CRUD dengan Eloquent

// CREATE — 2 cara
$produk = Produk::create(['nama' => 'Laptop', 'harga' => 8000000]);
// atau
$produk = new Produk();
$produk->nama   = 'Laptop';
$produk->harga  = 8000000;
$produk->save();

// READ
$semua   = Produk::all();
$satu    = Produk::find(1);                 // by primary key
$filter  = Produk::where('harga', '>', 5000000)->get();
$pertama = Produk::where('nama', 'Laptop')->first();

// UPDATE
Produk::where('id', 1)->update(['harga' => 9000000]);
// atau
$produk->harga = 9000000;
$produk->save();

// DELETE
Produk::destroy(1);    // by primary key
$produk->delete();    // instance method

Mass Assignment — $fillable

// Di Model, wajib definisikan $fillable agar create() bisa bekerja:
class Produk extends Model {
    protected $fillable = ['nama', 'harga', 'stok'];
}
Jebakan umum: Jika kolom tidak ada di $fillable, data diam-diam diabaikan tanpa error. Ini penyebab umum "data tidak tersimpan padahal tidak ada error".

Relasi Antar Tabel

RelasiMethodContoh
Satu-ke-SatuhasOne / belongsToUser punya 1 Profile
Satu-ke-BanyakhasMany / belongsToKategori punya banyak Produk
Banyak-ke-BanyakbelongsToManyUser punya banyak Role
// Contoh relasi hasMany:
class Kategori extends Model {
    public function produk() {
        return $this->hasMany(Produk::class);
    }
}
// Akses: $kategori->produk (lazy load) atau Kategori::with('produk')->get()
